# TCE2 Manual

TCE2 is an unofficial reconstruction and continued development of the
**True Combat: Elite mod layer** for Wolfenstein: Enemy Territory.
The TC:E-specific implementation has been rebuilt through binary analysis,
behavioral comparison and new source implementation. This is **not the original
proprietary TC:E source code**, an official TC:E release, or an engine replacement.
Retained SDK code and third-party components keep their own authorship and licenses.

The manual covers installing the mod, playing and configuring it, running a
server, using bots and Lua, and building the source. An existing TC:E asset
installation and a compatible external ET/ETLegacy engine are required.
